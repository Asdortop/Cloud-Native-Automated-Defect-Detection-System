💡 Key Design Decisions

          

            
⚡
ONNX Runtime (not PyTorch in prod)
~60 MB RAM vs 570 MB; pure PIL+NumPy preprocessing

            
🔁
At-least-once Kafka delivery
Manual offset commit only after Postgres write succeeds

            
🛡️
Zero-downtime RollingUpdate
maxUnavailable:0 — new pod ready before old terminates

            
📊
Weighted cross-entropy loss
Handles class imbalance in the NEU dataset automatically

            
🏷️
MLflow Model Registry gate
Recall ≥ 90% + no regression vs Production to promote

⚡ Quick Commands Reference

      

        

          
Local Stack (Docker Compose)

          
# Start all 9 services
docker compose -f docker/docker-compose.yml up -d

# Check all services
docker compose -f docker/docker-compose.yml ps

# Health probe
curl http://localhost:8080/health

# Run a prediction
curl -X POST http://localhost:8080/predict \
     -F "file=@data/raw/Crazing/img_001.bmp"

# View Prometheus metrics
curl http://localhost:8080/metrics

        

        

          
Kubernetes (Kind Cluster)

          
# Create Kind cluster with mounts
kind create cluster --config k8s/kind-config.yaml

# Load local image into Kind
kind load docker-image defect-serving:latest \
     --name defect-inspection

# Apply all K8s manifests
kubectl apply -f k8s/

# Watch pods and autoscaler
kubectl get pods -n defect-inspection -w
kubectl get hpa -n defect-inspection
